# Maven Tools Practice – Java Projects

This repository contains **practice projects for learning Maven build automation and Java project management**.  
It is designed for **hands-on learning and improving Java backend and build automation skills**.

## Projects Included

1. **Maven-App-01, Maven-App-02** – Basic Maven project setup and build automation  
2. **Maven-JDBC-App-03** – JDBC integration with Maven  
3. **Maven-webApp-04** – Web application development using Maven  
4. **HibernateProject-05** – Hibernate integration with Maven  
5. **BaseProject-06, ChildProject-07** – Multi-module Maven projects  
6. **FlipkartApp-08** – Mini e-commerce application project  
7. **MavenMultiModule** – Practice for Maven multi-module structure  
8. **Servers** – Server configuration examples  
9. **WishApp** – Additional Maven project practice  

## Technologies / Tools Used

- **Programming Language:** Java  
- **Build Tool:** Maven  
- **Database / ORM:** JDBC, Hibernate  
- **IDE / Tools:** STS / Eclipse  
- **Plugins:** Compiler Plugin, Surefire Plugin, etc.  

## Features

- Practice Maven **project structure, lifecycle, and dependency management**  
- Hands-on **multi-module Maven project development**  
- Integration with **JDBC and Hibernate**  
- Build and run **Java web applications** using Maven  

## Learning Outcomes

- Understand **Maven build lifecycle and plugins**  
- Learn **dependency and multi-module project management**  
- Practice **Java backend development with Maven**  
- Gain **hands-on experience with JDBC, Hibernate, and web app integration**
